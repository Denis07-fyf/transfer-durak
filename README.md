# Переводной дурак

Учебный проект ООП: Java 21, Maven, JUnit 5.

## Блок 1 — карты и колода
`Suit`, `Rank`, `Card`, `Deck`: 36 карт, козыри, сравнение карт и перемешивание по seed.

## Блок 2 — игроки и раздача
`Player` хранит карты; `GameState` раздаёт по шесть карт 2–4 игрокам и определяет, кто начинает. Открытый козырь остаётся последней картой колоды.

## Блок 3 — атака и защита
- `GameEngine.attack(playerIndex, card)`: начать атаку или подкинуть карту с уже лежащим достоинством.
- `GameEngine.defend(playerIndex, card, pairIndex)`: отбиться подходящей картой.
- `TablePair`: пара атака/защита на столе. Защита может быть пустой (`null`).
- `GameEvent`: журнал принятых ходов. Движок не печатает в консоль; демонстрационный вывод находится в `Main`.
- Проверяются очередь, наличие карты, достоинство для подкидывания, козыри и максимум атак (6, но не больше карт защитника на начало раунда).
- Неверный ход выдаёт `IllegalArgumentException` и не меняет стол, руки и журнал.

**Пока не реализовано:** перевод хода, завершение раунда («бито» / «взять»), добор, конец партии, боты, GUI. Эти шаги будут добавлены дальше. Программа в `Main` показывает только пример атаки и (если есть подходящая карта) защиты, а не полную партию.

## Запуск и тесты
1. Открыть проект в IntelliJ IDEA как Maven-проект, выбрать JDK 21.
2. Запустить `ru.vsu.durak.Main`.
3. В Maven → Lifecycle → test запустить тесты JUnit 5.

Новый блок содержит новые файлы и заменяет `Main.java`, `GameState.java`, `README.md`. Копируйте поверх предыдущего блока, не удаляя `.git`.
