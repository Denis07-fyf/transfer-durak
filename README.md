# Переводной дурак — блок 6

Проект для 2-й аттестации по ООП: Java 21, Maven, JUnit 5.

## Уже готово

- Колода 36 карт, козырь, раздача 2–4 игрокам, одинаковый `seed` даёт одинаковые раздачи.
- Атака, подкидывание, защита, перевод картой такого же достоинства.
- Дополнительное правило «проездного козыря» (показ козыря при открытой колоде). Его вариант необходимо согласовать с преподавателем.
- «Беру», «Бито», добор карт до шести в конце раунда, выход игроков и конец партии.
- `BotStrategy`: интерфейс стратегии с выбором атаки, защиты и перевода.
- `SimpleBot`: атакует и отбивается самой дешёвой картой, никогда не переводит.
- `TransferBot`: наследуется от `SimpleBot`, но сначала ищет допустимый перевод.
- `CardOrder`: компаратор сортировки (сначала некозырные карты, потом козыри).
- `BotGame`: проводит полную партию через `GameEngine`, не печатая в консоль.
- `Main`: выводит журнал полной партии двух ботов с `seed=42`.

## Как запустить

1. Открыть папку проекта через IntelliJ IDEA → **Open** (в папке есть `pom.xml`).
2. Выбрать **JDK 21**.
3. Запустить `src/main/java/ru/vsu/durak/Main.java`.
4. Запустить тесты через **Maven → Lifecycle → test**.

## Где показать требования преподавателю

- **Инкапсуляция** — `Player` и `GameState` хранят приватное состояние; руки выдаются через `List.copyOf`.
- **Абстракция, полиморфизм, паттерн Strategy** — `BotStrategy`, `SimpleBot` и `TransferBot`.
- **Наследование и переопределение** — `TransferBot extends SimpleBot`, `@Override chooseTransfer`.
- **Generics / коллекции** — `List<Card>`, `Deque<Card>`, `Set<Integer>`.
- **Comparator и лямбды** — `CardOrder.byStrength`.
- **Stream API** — `SimpleBot.chooseAttack`, `SimpleBot.chooseDefense`, `TransferBot.chooseTransfer`.
- **Разделение механики и вывода** — `GameEngine`, `GameState` и `BotGame` не печатают; только `Main` использует `System.out`.
- **Воспроизводимость** — `new GameState(..., seed)`; `BotGameTest.sameSeedProducesSameEventsAndResult`.
- **Ошибки ходов** — исключения `IllegalArgumentException` в `GameEngine`.

## Важные ограничения

- Сейчас `Main` запускает партию **бот против бота**, а не человека против компьютера.
- Боты простые и используют детерминированную стратегию. Данный блок реализует по одной атаке за ход с возможными подкидываниями только от текущего атакующего; остальные игроки не участвуют в подкидывании.
- Swing-интерфейс будет в следующем блоке. По требованиям нужен также консольный запуск — он уже есть.
- JSON, сохранение и турниры относятся к **3-й аттестации**.
- Правило «проездного» требует уточнения; на стандартный перевод картой это не влияет.
