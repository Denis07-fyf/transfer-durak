# Переводной дурак

Учебный проект по ООП: Java 21, Maven, JUnit 5.

## Блок 1 — карты и колода

- `Suit` — масти.
- `Rank` — достоинства карт.
- `Card` — карта и проверка отбоя.
- `Deck` — создание и перемешивание 36 карт.

## Блок 2 — игроки и раздача

- `Player` — имя и карты игрока.
- `GameState` — начальная раздача для 2–4 игроков, козырь и очередность.
- `Main` — временный консольный вывод начального состояния.

Начальный порядок карт воспроизводим: одинаковое значение `seed` даёт одинаковую раздачу.
Колода содержит 36 карт. Каждому игроку выдаётся 6 карт. Открытый козырь лежит внизу оставшейся колоды. Первым атакует игрок с младшим козырем; если козырей на руках нет, начинает первый игрок.

**Пока не реализовано:** атака, защита, перевод хода, добор и завершение партии. Они появятся в следующих блоках.

## Запуск

1. Открыть папку проекта в IntelliJ IDEA как Maven-проект.
2. Выбрать JDK 21.
3. Запустить `ru.vsu.durak.Main`.
4. Запустить тесты `CardTest` и `GameStateTest` или выполнить `mvn test`.
