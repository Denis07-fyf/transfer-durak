# Переводной дурак — вторая аттестация

Java 21 · Maven · JUnit 5 · стандартный Swing. **2-я аттестация, блок №7**.

## Что делает программа

- Раздаёт 36 карт двум-четырём игрокам и выбирает козырь.
- Выполняет атаку, подкидывание, защиту, обычный перевод, дополнительный «проездной» перевод.
- Позволяет объявить «Взять» или «Бито», добирает до шести карт, определяет проигравшего.
- Имеет двух простых ботов и автоматические партии с фиксированным `seed`.
- Имеет графический интерфейс для игры **человек против бота**. Все правила остаются в `GameEngine`.
- Сохраняет консольную демонстрацию партии **бот против бота**.

## Запуск

1. Откройте папку с `pom.xml` в IntelliJ IDEA, выберите JDK 21.
2. **Графика:** запустите `src/main/java/ru/vsu/durak/GuiMain.java`.
3. **Консоль:** запустите `src/main/java/ru/vsu/durak/Main.java`.
4. **Тесты:** `Maven → Lifecycle → test`.

### Управление графической игрой

- Нажмите на одну из **своих карт внизу**, чтобы выбрать её.
- Когда вы атакуете, нажмите **«Ход / подкинуть»**.
- Когда вы защищаетесь, выберите карту и нажмите **«Отбить»**. Если атак несколько, можно заранее выбрать нужную карту на столе.
- Для перевода выберите карту того же достоинства и нажмите **«Перевести»**.
- Для особого перевода показом козыря нажмите **«Проездной»**.
- Если не можете отбиться, нажмите **«Взять»**.
- Если все карты отбиты либо бот решил взять, нажмите **«Бито / завершить»**; когда атакует бот, он завершает раунд сам.
- **«Новая партия»** — ввод другого seed, например `42`. Повторение одного seed даёт одинаковую начальную раздачу.
- Если действие запрещено правилами, окно покажет причину в правой колонке, состояние не изменится.

## Тестирование — 20 сценариев

`src/test/java/ru/vsu/durak/BasicGameTest.java` содержит ровно **20 тестов** на карты, раздачу, ошибки ходов, защиту и взятие, переводы (включая проездной), полную партию, сохранность карт и воспроизводимость.

**Важно при обновлении с блока 6:** удалить 6 устаревших файлов `*Test.java` из `src/test/java/ru/vsu/durak/model`, иначе останутся старые 92 теста. Новый `BasicGameTest.java` лежит в соседнем пакете `ru.vsu.durak` — удалять его не надо.

## Где показать требования по ООП

- **Инкапсуляция:** закрытые поля `Player`, `GameState`, неизменяемые копии списков.
- **Enum / record:** `Suit`, `Rank`, `Card`, `TablePair`, `GameEvent`.
- **Интерфейсы и полиморфизм:** `BotStrategy` и разные реализации выбора ходов.
- **Наследование / переопределение:** `TransferBot extends SimpleBot` и `@Override`.
- **Коллекции и обобщённые типы:** `List<Card>`, `Deque<Card>`, `Set<Integer>`.
- **Comparator и лямбды:** `CardOrder.byStrength`.
- **Stream API:** `SimpleBot.chooseAttack`, `SimpleBot.chooseDefense`.
- **Паттерн Strategy:** стратегии ботов можно менять, не меняя `GameEngine`.
- **Отделение логики и интерфейса:** `GameEngine` не печатает и ничего не знает о Swing; окно только вызывает его методы.
- **Исключения:** недопустимые ходы обрабатываются через `IllegalArgumentException`.
- **Воспроизводимость:** один и тот же `seed` и те же решения дают ту же партию.

## Известные упрощения

- В графической версии два игрока; движок и консольный код поддерживают до четырёх.
- Боты используют простые, а не оптимальные стратегии, графический интерфейс не анимирован.
- В режиме с ботом автоматическое подкидывание выполняет только текущий атакующий.
- **«Проездной» козырь** — дополнительное локальное правило: при непустой колоде подходящий козырь можно показать, не выкладывая. В некоторых вариантах переводного дурака его нет; правило желательно согласовать с преподавателем.
- Сохранение в JSON, загрузка, турниры и многопоточность относятся к **третьей аттестации**.
