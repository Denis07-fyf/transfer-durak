# Переводной дурак

Учебный проект по ООП (Java 21, Maven, JUnit 5).

## Этап 1 — карты и колода

- `Suit` — масти.
- `Rank` — достоинства карт.
- `Card` — неизменяемая карта и проверка отбоя.
- `Deck` — создание и перемешивание колоды из 36 карт.
- `Main` — временный пример работы с колодой.

## Запуск

Открыть `pom.xml` в IntelliJ IDEA как Maven-проект. Запустить `ru.vsu.durak.Main`.

Тесты: `mvn test` или запуск класса `CardTest` из IntelliJ IDEA.

При перемешивании используем переданный `Random` — одинаковый seed приводит к одинаковому порядку карт.
