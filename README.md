# Переводной дурак — блок 5

Учебная игра на Java 21, Maven, JUnit 5. Правила находятся в `model` и не используют `System.out`.

## Что уже реализовано

- Колода 36 карт, козырь, раздача 2–4 игрокам. Один `seed` даёт одинаковую начальную раздачу.
- Атака, подкидывание карт того же достоинства, защита козырями или старшими картами той же масти.
- Перевод неотбитой атаки картой того же достоинства с проверкой, хватит ли карт следующему защитнику.
- Спорный вариант «проездного козыря»: показ подходящего козыря, пока нижний козырь открыт; показать один раз за раунд. Правило требует согласования с преподавателем.
- `take(defender)` — объявить «Беру»; после этого разрешены дополнительные подкидывания в рамках лимита.
- `finishRound()` — завершить раунд: **Бито** только если все карты отбиты; **Взять** после объявления взятия.
- После раунда игроки добирают карты до шести: атакующий в начале раунда первым, остальные по очереди, защитник последним.
- Отбой сохраняется отдельно; после опустошения колоды вышедшие игроки пропускаются. Когда остаётся один игрок с картами, он проиграл; если нет ни одного — ничья.
- События каждого действия, ошибки неверных ходов без изменений состояния.

## Как запустить

1. IntelliJ IDEA → Open → папка с `pom.xml` → JDK 21.
2. `ru.vsu.durak.Main` показывает один законченный раунд.
3. IntelliJ → Maven → Lifecycle → `test` запускает тесты JUnit 5. Если терминал не знает `mvn`, используйте встроенный Maven IDEA.

## Как устроены главные методы

- `GameEngine.attack(...)` — атака/подкидывание; `defend(...)` — защита; `transfer(...)` — перевод.
- `take(...)` — решение защитника взять карты. До `finishRound()` противники могут подкинуть ещё карты.
- `finishRound()` — подтверждение завершения раунда и вызов `GameState.completeRound()`.
- `GameState` хранит руки, стол, колоду, отбой и очередь ходов.

## Ограничения блока 5

- В `Main` пока демонстрация **одного** раунда, не интерактивная партия.
- В тестах есть полные двухпользовательские партии с простым детерминированным выбором ходов (по одной атаке за раунд), но отдельные игровые боты и пользовательский ввод будут следующим этапом.
- Нет GUI, стратегии ботов, сортировки карт, сохранения JSON и турниров. JSON/турниры относятся к третьей аттестации.
- Спорные вариации правил (особенно «проездной козырь») необходимо согласовать с преподавателем.
